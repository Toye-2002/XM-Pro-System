# XM-Pro-System
这是大学期间完成的第一个小项目。后台管理系统（The first small project completed during college. Back-end Management System）。
XM-Pro-System是一套后台管理系统，包括前台系统以及后台管理系统，基于SpringBoot3 + Vue3 + MyBatis实现的。暂时没有部署到服务器上。前台系统包含内容包含首页、数据统计、文章管理、部门管理、用户管理、个人信息、修改密码。后端系统包含统计数据、导入导出员工信息表（以Excel表导入以及导出，可以实现批量添加员工以及导出员工信息）、权限管理模块等。
